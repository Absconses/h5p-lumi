Un skill **`h5p-lumi`** existe dans `C:\Users\ppempie\.claude\skills\h5p-lumi`. Il génère du contenu H5P importable dans Lumi : frises **Timeline**, QCM/quiz **MultiChoice / QuestionSet**, et **tout autre type** du catalogue via lecture du `semantics.json` contenu dans un gabarit.

**Décisions de conception :**
- Empaquetage `.h5p` par la **méthode du gabarit** : réutiliser une activité du même type exportée une fois depuis Lumi (garantit la compatibilité de version). Les gabarits vont dans `assets/templates/`.
- Images : uniquement de **vraies** images Wikimedia validées HTTP 200 (`scripts/Find-WikimediaImages.ps1`), jamais inventées.
- Les scripts `.ps1` doivent être en **UTF-8 AVEC BOM** (sinon PowerShell 5.1 corrompt les accents et plante).

**Statut :** opérationnel pour les frises. L'utilisateur a fourni un **gabarit Timeline** (rangé dans `assets/templates/gabarit-timeline.h5p`) ; un vrai `.h5p` de frise a été produit et vérifié. Pour empaqueter des **quiz**, il manque encore un gabarit **QuestionSet/MultiChoice** à exporter depuis Lumi.
